From command to shaft, the whole control loop

We design every stage a position command passes through before it becomes motion at the motor shaft.

  1. Position and speed control

    Cascaded position and speed loops, tuned to follow the target through load changes and disturbances.

  2. FOC current control

    Field-oriented control of PMSMs to command torque directly. The current-loop bandwidth sets the response of every loop above it.

  3. Inverter and power stage

    IGBT gate drive, current and voltage sensing, over-current and thermal protection, and the heat-sink design.

  4. Position sensing/tracking

    Resolvers and digital position sensors such as BiSS-C, and fusion of several sensor signals for higher absolute accuracy.

  5. State estimation

    Kalman filters that estimate position, speed and acceleration while reducing the effect of sensor noise and delay.

  6. Embedded firmware

    Real-time control cycles, communication and diagnostics on TI C2000 dual-core DSPs.

All hardware is designed with EMC, grounding and shielding, and military-standard (MIL-STD) requirements in mind.

From requirements to production

One team carries the work from start to finish, so nothing gets lost between stages.

  1. Requirements

    Agree on operating conditions, interfaces and test criteria.

  2. Design

    Design the control algorithm, circuits and firmware structure, and check them in simulation.

  3. Prototype

    Build the boards and harnesses, load the firmware and run it against a real load.

  4. Test and verification

    Prepare performance, environmental and EMC tests and document the results.

  5. Production and support

    Hand over production documentation and solve field issues together.
